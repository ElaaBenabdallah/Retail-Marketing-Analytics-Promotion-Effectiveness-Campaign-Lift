# Retail Promotion Performance & Store Lift Analysis (GreenTrail Outdoors)

## 📌 Executive Summary
An end-to-end retail analytics case study evaluating the effectiveness of promotional campaigns across 20 retail stores. Built entirely in **Power BI** using advanced **Power Query ETL** and **DAX measures** to analyze incremental revenue, foot traffic elasticity, and post-campaign demand.

## 📊 Key Findings & Insights
* **Urban vs. Suburban Performance**: Urban stores generated a **41.8% average sales lift** compared to **28.2% in Suburban locations**.
* **Campaign Vehicle ROI**: Special Events drove the highest sustained residual lift (+9.9%), whereas Buy-One-Get-One (BOGO) promotions triggered a negative post-promo "hangover" effect (-1.94%).
* **Traffic Conversion**: Uncovered a mismatch in traffic-to-sales efficiency where certain locations drew high foot traffic but low basket conversion.

## 🛠️ Tech Stack & Skills Demonstrated
* **Tooling**: Power BI Desktop, Power Query, DAX, Excel.
* **Methodology**: Promotional lift modeling, segmentation, KPI metric architecture, and executive dashboard design.
